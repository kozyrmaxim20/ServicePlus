## СервисПлюс — система учёта заявок сервисного центра

Приложение для учёта и управления заявками сервисного центра, разработанное на языке C# с использованием Windows Forms и базы данных SQLite.

## Цель проекта

Разработать приложение с графическим интерфейсом для автоматизации учёта заявок сервисного центра, хранения информации в реляционной базе данных SQLite и организации доступа пользователей с различными ролями.

## Описание проекта

СервисПлюс — программа, предназначенная для автоматизации учёта заявок сервисного центра.

Приложение позволяет авторизовывать пользователей, просматривать информацию о клиентах, создавать заявки на ремонт устройств и сохранять данные в базе данных.

Система разработана для замены ручного ведения заявок в таблицах Excel на централизованное хранение информации.

## Возможности

- Авторизация пользователей по логину и паролю.
- Разграничение прав доступа по ролям `admin` и `user`.
- Переход в главное меню после успешной авторизации администратора.
- Просмотр списка клиентов в таблице DataGridView.
- Создание новых заявок на обслуживание устройств.
- Выбор клиента из выпадающего списка.
- Указание устройства и описания неисправности.
- Выбор статуса заявки.
- Сохранение заявок в базе данных SQLite.
- Обработка ошибок при некорректных действиях пользователя.
- Графический интерфейс Windows Forms.

## Используемые технологии

- **Язык программирования:** C#
- **Платформа:** .NET
- **Графический интерфейс:** Windows Forms
- **База данных:** SQLite
- **Язык запросов:** SQL
- **Среда разработки:** Visual Studio

## Структура базы данных

Для хранения информации используется реляционная база данных SQLite, организованная в соответствии с третьей нормальной формой (3НФ).

База данных включает пять таблиц:

- **Users** — учётные записи пользователей.
- **Roles** — роли пользователей.
- **Requests** — заявки на обслуживание устройств.
- **Devices** — информация об устройствах.
- **Statuses** — статусы заявок.

Для каждой заявки предусмотрено хранение информации о клиенте, устройстве, описании проблемы, статусе и дате создания.

## Принцип работы

### Авторизация

1. Пользователь запускает приложение.
2. Вводит логин и пароль.
3. Программа проверяет введённые данные в базе SQLite.
4. При неверных данных отображается сообщение об ошибке.
5. При авторизации с ролью `admin` открывается главное меню.
6. При авторизации с ролью `user` отображается сообщение «Функционал в разработке».

### Главное меню

После успешной авторизации администратора открывается главная форма приложения, содержащая разделы:

- **Заявки** — создание и сохранение заявок сервисного центра.
- **Клиенты** — просмотр информации о клиентах.

### Работа с клиентами

1. Пользователь открывает раздел «Клиенты».
2. Программа загружает информацию о клиентах из базы данных.
3. Список клиентов отображается в таблице DataGridView.

### Создание заявки

1. Пользователь открывает раздел «Заявки».
2. Выбирает клиента из выпадающего списка.
3. Указывает устройство.
4. Вводит описание неисправности.
5. Выбирает статус заявки: «Новая», «В работе», «Готова» или «Выдана».
6. Сохраняет заявку.
7. Информация записывается в базу данных SQLite.
